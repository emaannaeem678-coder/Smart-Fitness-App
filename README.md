Smart Fitness App
Overview

Smart Fitness App is a web-based fitness tracking application developed using HTML, CSS, and Java . The system helps users monitor their fitness activities and provides useful tools for maintaining a healthy lifestyle.

The application allows users to register, log in, calculate BMI and calories, receive workout recommendations, view wellness tips, explore diet suggestions, and submit feedback.
